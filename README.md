# 🌾 AgriHub

> Empowering Farmers. Connecting Buyers. Building the Future of Agriculture.

AgriHub is a full-stack MERN web application that connects farmers and buyers on a single platform. It helps farmers showcase their crops, reach customers directly, and access modern digital agriculture services while reducing dependency on intermediaries.

## 🚀 Live Demo

🔗 https://agrihub-tap.vercel.app/

---

## 📖 About the Project

AgriHub is designed to simplify agricultural trading by creating a transparent marketplace where farmers can sell their produce directly to buyers.

The platform focuses on improving communication, reducing middlemen, and making agriculture more accessible through technology.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/Nitheesh-v/agrihub.git
```

### Install dependencies

```bash
cd agrihub
npm install
```

### Start the application

```bash
npm start
```
